# VAD 自动录音功能设计文档

## 一、产品计划 (Product Plan)

### 1.1 功能目标
实现语音活动检测（VAD），当检测到用户说话时自动触发"开始录音"，用户停止说话后自动触发"停止录音"。

### 1.2 页面结构
```
test/
├── test_page.html       # 主页面 - 添加"自动录音"开关
├── test_voice.html      # 新增 - 音量检测测试页面
├── css/
│   ├── test_page.css
│   └── test_voice.css   # 新增 - 测试页面样式
└── js/
    ├── core/audio/
    │   ├── recorder.js
    │   └── vad.js       # 新增 - VAD检测模块
    └── test_voice.js    # 新增 - 测试页面逻辑
```

### 1.3 用户操作路径

**测试页面 (test_voice.html):**
1. 打开页面 → 点击"开始监听"
2. 调整阈值滑块 → 观察音量变化
3. 说话测试 → 观察触发预测
4. 查看日志 → 确认阈值合适

**主页面 (test_page.html):**
1. 连接服务器 → 开启"自动录音"开关
2. 说话 → 自动开始录音
3. 停止说话 → 自动停止录音

## 二、状态与数据计划 (State & Data Plan)

### 2.1 VAD 状态机

```
┌─────────┐     start()      ┌─────────┐
│  IDLE   │ ───────────────→ │LISTENING│
└─────────┘                  └─────────┘
     ↑                            │
     │                            │ volume > threshold
     │                            │ 持续 200ms
     │                            ↓
     │                       ┌─────────┐
     │      stop()           │ SPEAKING│
     └────────────────────── │ (录音中) │
                             └─────────┘
                                  │
                                  │ volume < threshold
                                  │ 持续 1000ms
                                  ↓
                             触发停止录音
                                  │
                                  ↓
                             回到 LISTENING
```

### 2.2 数据模型

```javascript
// VADDetector 状态
{
    isListening: boolean,      // 是否在监听
    isRecording: boolean,      // 是否在录音
    currentVolume: number,     // 当前音量 (0-100)

    // 计时器
    speakingTimer: null,       // 说话计时器
    silenceTimer: null,        // 静音计时器

    // 时间戳
    speakingStartTime: null,   // 开始说话时间
    silenceStartTime: null,    // 开始静音时间
}

// 配置参数
{
    volumeThreshold: 30,       // 音量阈值 (0-100)
    startDelay: 200,           // 开始触发延迟 (ms)
    stopDelay: 1000,           // 停止触发延迟 (ms)
}
```

### 2.3 数据流向

```
麦克风 → AnalyserNode → 获取音量 → VAD检测器
                                    ↓
                            判断是否触发录音
                                    ↓
                        ┌───────────┴───────────┐
                        ↓                       ↓
                onStartRecording()      onStopRecording()
                        ↓                       ↓
                audioRecorder.start()   audioRecorder.stop()
```

## 五、组件/系统计划 (Component/System Plan)

### 5.1 VADDetector 类

```javascript
class VADDetector {
    // 配置
    volumeThreshold    // 音量阈值 (0-100)
    startDelay         // 开始触发延迟 (ms)
    stopDelay          // 停止触发延迟 (ms)

    // 状态
    isListening        // 是否监听中
    isSpeaking         // 是否在说话
    currentVolume      // 当前音量

    // 回调
    onVolumeChange     // 音量变化回调
    onSpeakingChange   // 说话状态变化回调
    onStartRecording   // 触发开始录音回调
    onStopRecording    // 触发停止录音回调

    // 方法
    start()            // 开始监听
    stop()             // 停止监听
    setThreshold(val)  // 设置阈值
}
```

### 5.2 触发逻辑

```javascript
// 音量检测循环 (每50ms)
function detectVolume() {
    const volume = getVolume();  // 0-100
    onVolumeChange(volume);

    if (volume > threshold) {
        // 音量超过阈值
        clearSilenceTimer();

        if (!isSpeaking) {
            // 开始计时
            speakingStartTime = Date.now();
            isSpeaking = true;
        }

        // 检查是否达到触发条件
        const duration = Date.now() - speakingStartTime;
        if (duration >= startDelay && !isRecording) {
            onStartRecording();
            isRecording = true;
        }
    } else {
        // 音量低于阈值
        if (isSpeaking) {
            clearSpeakingTimer();
            silenceStartTime = Date.now();
            isSpeaking = false;
        }

        // 检查是否达到停止条件
        if (isRecording) {
            const duration = Date.now() - silenceStartTime;
            if (duration >= stopDelay) {
                onStopRecording();
                isRecording = false;
            }
        }
    }
}
```
